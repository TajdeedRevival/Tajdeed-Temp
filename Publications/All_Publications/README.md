## How to Add a New Publication

When adding a new publication:

1. Upload the file to the appropriate subject folder.
2. Copy the file name and location.
3. Add the publication to the table above.
4. Link the publication title to the uploaded file.
5. Add the subject, author name and format.

### Example

If you upload:

```text
Publications/Islamic_Thought/Tawheed/Understanding_Tawheed.pdf
```

Add the following row to the catalogue:

```markdown
| [Understanding Tawheed](../Islamic_Thought/Tawheed/Understanding_Tawheed.pdf) | Tawheed | Author Name | PDF |
```

This will appear in the table as:

| Publication                                                                   | Subject | Author Name | Format |
| ----------------------------------------------------------------------------- | ------- | ----------- | ------ |
| [Understanding Tawheed](../Islamic_Thought/Tawheed/Understanding_Tawheed.pdf) | Tawheed | Author Name | PDF    |

## Adding a PDF to the Repository

PDFs should be uploaded into the appropriate subject folder rather than directly into the **All Publications** folder.

For example:

```text
Publications/
└── Islamic_Thought/
    └── Tawheed/
        ├── README.md
        └── Understanding_Tawheed.pdf
```

### Uploading a PDF using GitHub

1. Open the **Tawheed** folder in the GitHub repository.
2. Click **Add file**.
3. Select **Upload files**.
4. Drag your PDF into the upload area, or click **choose your files**.
5. Wait for the upload to finish.
6. Scroll down to **Commit changes**.
7. Click **Commit changes**.

The PDF is now stored in the repository.

You can then return to:

```text
Publications/All_Publications/README.md
```

and add it to the catalogue.

---

## Adding a PDF to the Catalogue

For example, if your uploaded file is:

```text
Publications/Islamic_Thought/Tawheed/Understanding_Tawheed.pdf
```

The link from the **All Publications** page is:

```markdown
[Understanding Tawheed](../Islamic_Thought/Tawheed/Understanding_Tawheed.pdf)
```

So your table entry would be:

```markdown
| [Understanding Tawheed](../Islamic_Thought/Tawheed/Understanding_Tawheed.pdf) | Tawheed | Author Name | PDF |
```

### Important

The PDF should **only be uploaded once**.

Do not upload another copy of the same PDF into `All_Publications`.

`All_Publications/README.md` is simply the **master catalogue** that links to the original files.
